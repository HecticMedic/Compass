Connect Claude

Compass talks to Claude using an API key from Anthropic. It's set up once and stays on this phone only.

  1. Go to console.anthropic.com and sign in (or create an account).
  2. Add a payment method under Billing. Use is billed separately from a Claude subscription, usually a few cents per chat.
  3. Under API keys, create a key and copy it.
  4. Paste it below.
